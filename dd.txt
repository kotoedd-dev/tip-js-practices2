# Подготовка к защите КР2

Автор: Вагелист Дмитрий Эдуардович, ЭФБО-15-25. Дата: 15.11.2026.

1. **validateTaskDraft** проверяет введённые поля до изменения задач. ПР4 возвращает ok и value либо errors. ПР6 возвращает valid, value и errors, поскольку сервер сам назначает id.
2. **trim()** удаляет пробелы с краёв строки. Строка из одного пробела превращается в пустую и не проходит проверку. Пробелы внутри названия сохраняются.
3. **localStorage** — хранилище строк в браузере для конкретного адреса сайта. Данные остаются после перезагрузки. Другой порт — другое хранилище. В ПР4 ключ tip-js-practice-04:demo. В ПР6 задачи берутся с сервера.
4. **JSON.stringify** превращает объект с version и tasks в строку для сохранения. **JSON.parse** восстанавливает объект. После parse проверяем версию, типы полей и уникальность id, поскольку корректный JSON ещё не означает корректные задачи.
5. **getTasks** проверяет фильтры, отправляет GET /tasks с query-параметрами, проверяет ответ и возвращает tasks и meta. false нельзя потерять как «пустое» значение.
6. **API** — правила, по которым клиент обращается к серверу. **fetch** отправляет HTTP-запрос и возвращает Promise с ответом.
7. **async/await** позволяют дождаться ответа без блокировки страницы. **try/catch** перехватывает ошибку и позволяет показать понятное сообщение.
8. **404** — сервер ответил, но запись не найдена. fetch обычно успешно возвращает Response даже для 404/500, поэтому отдельно проверяем response.ok. Сетевая ошибка и HTTP-ошибка — разные ситуации.
9. **GET** читает данные. **PATCH** меняет переданные поля записи; например completed: true. В запросе указываем JSON-тело и Content-Type: application/json.
10. После **PATCH** повторяем **GET** с текущими фильтрами, чтобы получить подтверждённое состояние сервера. Если установлен completed=false, завершённая задача исчезает из результата.
11. AbortController отменяет предыдущую загрузку. Дополнительно номер sequence не позволяет старому ответу перерисовать новый список. В finally снимаем блокировку кнопок.
12. Названия выводятся через textContent, поэтому введённая HTML-разметка отображается как текст.

Практический показ: запустить ПР4, добавить №20 и обновить страницу; затем ПР6, сбросить набор, применить completed=false, завершить №4 и показать PATCH → GET в Network.

Ограничение: API ПР6 хранит данные в памяти процесса. Перезапуск API восстанавливает исходный набор. Номер индивидуального варианта не предоставлен; используется общий набор согласно КР2.
